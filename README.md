# ChatGPT-2-TextExtract

Extract text from an image using Tesseract.js OCR. Give it an image path, it prints the recognized text.

## Usage

```sh
npm install
node index.js <path-to-image>
```

Example:

```sh
node index.js photo.png
```

The English language data downloads automatically on first run (internet required once); afterwards it works offline.
